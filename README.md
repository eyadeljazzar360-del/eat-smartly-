# Eat Smart Pro — كُل بذكاء

Bilingual Arabic/English web app prototype for families with children ages 4–10.

## Features
- Responsive dashboard with daily overview and quick actions.
- Weekly planner with 7 days and 5 meal slots per day.
- Recipe browsing, text search, category filters, and add-to-plan / add-ingredients-to-shopping actions.
- Pantry ingredient matcher with suggested recipe matches.
- Shopping list with categories, check-off progress, starter suggestions, and remove controls.
- Child profile with age, allergies, dislikes, and notes.
- Daily habit checklist.
- Arabic/English language toggle.
- Browser local storage.

## Run locally
Extract the ZIP and open `index.html` in Chrome, Edge, or another modern browser. Keep `index.html`, `styles.css`, and `app.js` in the same folder.

## Free hosting with GitHub Pages
1. Create/sign in to https://github.com
2. Create a public repository, e.g. `eat-smart-pro`.
3. Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the repository root.
4. Go to **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. Wait for the deployment; the URL will resemble `https://YOUR-USERNAME.github.io/eat-smart-pro/`.

## Prototype limitations
- No server, account login, cloud sync, notifications, or app-store package.
- Data is stored locally in the current browser/device and does not automatically transfer to another device.
- Allergy/dislike filtering is simple keyword matching and cannot guarantee safety or catch all ingredients, translations, hidden allergens, or cross-contact. Always check labels and seek qualified advice for medical/dietary concerns.
- Recipe ideas are general examples, not individualized nutrition advice. Ensure food is age-safe and prepared safely.


## تحديث مكتبة الوصفات
- تحتوي المكتبة على أكثر من 60 وصفة مناسبة كأفكار لأطفال 4–10 سنوات.
- اضغط «طريقة التحضير» في أي بطاقة لعرض المقادير والخطوات.
- يمكن إضافة الوصفة إلى خطة الأسبوع أو إضافة مكوناتها إلى قائمة المشتريات.
- وصفات الحساسية والتفضيلات تعتمد على مطابقة نصية مبدئية فقط؛ راجع كل ملصق ومكوّن بنفسك.
- ينبغي أن يتولى البالغ السكاكين والفرن والطهي الساخن، وأن تكون قطع الطعام مناسبة لقدرة الطفل على المضغ.
